# Chroma Grid Cards

A responsive, colourful card gallery built with React and Vite. Hover or focus a card to reveal its chromatic spotlight effect.

## Features

- Six themed cards: Hogwarts, Books, Crochet, Iceland, New York and Science
- Responsive grid layout
- Animated colour glow on hover and keyboard focus
- Built with React, JavaScript and CSS
- No external UI libraries required

## Run locally

1. Install [Node.js](https://nodejs.org/).
2. Open this folder in VS Code.
3. Open the terminal and run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL printed in the terminal (usually `http://localhost:5173/`).

## Create a production build

```bash
npm run build
```

The production files will be created in the `dist` folder.

## Upload with GitHub Desktop

1. Extract this ZIP file.
2. Open GitHub Desktop and sign in.
3. Select **File → Add Local Repository**.
4. Choose the extracted `chroma-grid-cards` folder.
5. If GitHub Desktop says it is not a Git repository, choose **Create a repository** and use the same folder.
6. Enter a summary such as `Initial Chroma Grid Cards project`.
7. Click **Commit to main**.
8. Click **Publish repository**, choose **Public** if you want to share it, then publish.

Do not upload the `node_modules` folder. It is generated automatically by `npm install`.
